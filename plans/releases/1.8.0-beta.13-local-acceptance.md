## Product defects fixed before this candidate

1. **Terminal source events could disappear while the summary became FAILED.**
   Ordinary Init/rebuild then allowed a failed detached attempt to resume.
   [Core #66](https://github.com/NL-BioImaging/biomero/pull/66) fixes borrowed-session
   ownership, cold status hydration and the rebuild boundary. A fresh live
   failure/restart/rebuild test passes. The original automatic-resumption evidence
   is preserved; no manual replay or repair was used to make it pass.
2. **Fresh v3 Plate verification tried to open v2 metadata.**
   [Scripts #72](https://github.com/NL-BioImaging/biomero-scripts/pull/72) reuses the
   existing version-aware reader. Fresh live v3 Plate verification now follows the
   intended shallow path instead of a safe full-result fallback.
3. **Renaming label directories broke metadata references.**
   [Scripts #75](https://github.com/NL-BioImaging/biomero-scripts/pull/75) removes
   the unnecessary rename and metadata-rewrite code. Final v2/v3 runs preserve
   native paths, pixels, provenance, NGFF links and adjacent RO-Crate links.
   Previously renamed results are not automatically repaired.

One test-runner defect passed incorrect keyword names to Fabric's native transfer
method, failing before the intended ZIP fault. It was corrected in the public
runner, with a real-Fabric/native-BIOMERO regression; both live ZIP modes then
passed. Fixture/verifier corrections for plane ordering, supported crate placement
and full-versus-shallow registration contracts remain in the local evidence.
Earlier failures were preserved rather than converted into successful runs.
