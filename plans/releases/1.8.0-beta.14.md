# NL-BIOMERO 1.8.0-beta.14: release clean-up and acceptance

Status on 13 November 2026: **in preparation**. Components are still being
reviewed and released; nothing below is tested yet.

This beta carries the clean-up of the code added during the 2.9 prerelease
series, so that it is ready for the first stable 1.8 release, plus the security
updates found on the way.
