# NL-BIOMERO 1.8.0-beta.15: release clean-up and acceptance

Status on 19 November 2026: **in preparation**. Local acceptance ran against the
current pins; see [the local acceptance report](1.8.0-beta.15-local-acceptance.md).
Core and scripts 2.9.0b29 are still to land, so rows 5, 6, 7 and 16 are rerun after them.

This beta carries the clean-up of the code added during the 2.9 prerelease
series, so that it is ready for the first stable 1.8 release, plus the security
updates found on the way.
