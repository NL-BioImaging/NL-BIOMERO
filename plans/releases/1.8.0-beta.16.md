# NL-BIOMERO 1.8.0-beta.16: fixes from ACC acceptance of beta.15

Status on 23 November 2026: **locally accepted, released for ACC** (core and
scripts 2.9.0b33; all rows pass locally, see the local acceptance report).
ACC's final report of
23 November 2026 did not accept
[1.8.0-beta.15](https://github.com/NL-BioImaging/NL-BIOMERO/releases/tag/v1.8.0-beta.15); its one named product failure
is #119. Local acceptance of this beta then found #123. This beta carries only
the fixes for findings that block acceptance. Stable 1.8.0 is released from the
beta ACC accepts.

## ACC findings on 1.8.0-beta.15

ACC reports findings as commits on its deploy branch; the coordinator files
them as issues and answers here. Board: [Release = 1.8.0-beta.16](https://github.com/orgs/NL-BioImaging/projects/2?filterQuery=release%3A%221.8.0-beta.16%22).

| A workflow stays failed after Slurm requeues and completes a node-failed job | [#120](https://github.com/NL-BioImaging/NL-BIOMERO/issues/120) | Later: NODE_FAIL was already final in core 2.9.0b25, not a regression | - |
| A busy canonical lock on CIFS is logged as "unavailable" | [BIOMERO.importer#65](https://github.com/NL-BioImaging/BIOMERO.importer/issues/65) | Later: safe, the workflow falls back to a normal export | - |
